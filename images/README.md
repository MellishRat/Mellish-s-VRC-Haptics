The shared editable Fritzing project is available as
[`layout.fzz`](layout.fzz). It contains the breadboard layouts for both the
stable two-channel build and the experimental 16-channel controller. Open it
with Fritzing to inspect or modify the layouts, and follow the applicable
project's wiring and safety guidance before building or applying power.
